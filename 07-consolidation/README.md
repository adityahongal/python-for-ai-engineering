# 07 — Consolidation

An end-to-end program that ties the whole track together: fetch data over HTTP, validate it, handle
failures, and write clean JSON back out. The same shape as a real LLM pipeline.

## Notes

**The pipeline**
```
HTTP GET (httpx) → JSON → Pydantic validate → error-handled → model_dump() → saved JSON file
```
Swap the GitHub API for an LLM API and this is a GenAI app: `httpx.post` with the prompt in the body
and the API key in the headers → JSON response → validate → use.

**HTTP with httpx**
- `httpx.get(url)` sends the request; `response.status_code` reports the outcome (200/404/500…);
  `response.json()` parses the body into a dict.
- `response.raise_for_status()` converts a 4xx/5xx status into an exception so `except` can catch it.
- `httpx.HTTPError` is the base class for both network failures and bad statuses — one handler covers both.

**Validation & resilience**
- The API returns ~30 fields; the `GitHubUser` model keeps only the four declared (Pydantic filters the rest).
- `name` is `str | None` because GitHub returns `null` when no display name is set.
- `try/except` catches `httpx.HTTPError` (network/status) and `ValidationError` (bad shape) so one bad
  response never crashes the program.

**Output**
- The validated model is written to `profile.json` via `model_dump()` + `json.dump(..., indent=4)`,
  using a `Path(__file__).parent` path. `profile.json` is generated on each run (git-ignored).

## Gotchas
- A 404/500 is not automatically an exception in httpx — call `raise_for_status()`.
- Nullable API fields (`null` → `None`) need `str | None`, or Pydantic rejects them.
- `profile.json` is derived output — regenerated by running the script, not committed.

## Files
- `main.py` — end-to-end pipeline: `httpx` GET → `GitHubUser` (Pydantic) → `try/except`
  (`httpx.HTTPError` + `ValidationError`) → `model_dump()` → `profile.json`, wrapped in `main()` behind
  the `if __name__ == "__main__":` guard.

## Run
```bash
cd 07-consolidation
python main.py        # prints the profile and writes profile.json
```
